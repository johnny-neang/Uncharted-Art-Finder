# Sacramento Artist Directory — Arden Fair UnchARTed

A self-contained, offline-first dashboard cataloging 21 Sacramento-area artists
and art agencies, evaluated for the Arden Fair UnchARTed program. Curated by
UpperCloud Studio.

## Files

| File | What it is |
|---|---|
| `sacramento-artist-directory-with-photos.html` | The dashboard. Open it in any browser, online or offline. |
| `fetch_artist_images.py` | Scrapes each artist's site / gallery rep for two representative images, resizes them, saves as base64 in `artist_images.json`. |
| `inject_images.py` | Reads `artist_images.json` and/or `local_files/` and produces `…with-photos.LOCAL.html` with real photos in place of the stylized SVGs. |
| `local_files/` | Drop manually-saved photos here. Naming: `<slug>-1.jpg`, `<slug>-2.jpg`. See slug list in `inject_images.py`. |
| `artist_images.json` | Cache of base64-embedded images keyed by artist slug (regenerated by `fetch_artist_images.py`). |

## What ships out of the box

The current `sacramento-artist-directory-with-photos.html` uses **hand-crafted
SVG illustrations** that reflect each artist's signature visual style — text-figure
work for Bryan Valenzuela, koi for Maren Conrad, geometric California Bear for
Raphael Delgado, sugar skulls for John S. Huerta, and so on. Forty-two
illustrations across twenty-one entries.

These are intentionally stylized, not faked photographs. They give the dashboard
a coherent editorial feel out-of-the-box and let it ship without external image
dependencies.

## Swapping in real photos

Two paths:

### Path A: scripted (when running outside a sandboxed agent)

```bash
pip install requests beautifulsoup4 pillow
python fetch_artist_images.py        # populates artist_images.json
python inject_images.py              # writes …with-photos.LOCAL.html
```

The fetcher tries multiple URLs per artist (artist site → gallery rep →
Wide Open Walls → press), filters out logos / icons / thumbnails, validates
with Pillow, resizes to 480px wide, and saves as base64.

### Path B: manual (always works)

Save any photos you want into `local_files/` named:

```
local_files/valenzuela-1.jpg
local_files/valenzuela-2.jpg
local_files/conrad-1.png
…
```

Then:

```bash
pip install pillow
python inject_images.py
```

Local files override anything in `artist_images.json`. Anything missing keeps
its SVG fallback — there's never a broken image.

The slug list is at the top of `inject_images.py`.

## Note on this build

This dashboard was assembled inside an environment with restricted egress
(only github.com reachable). Every artist domain, gallery rep CDN, and press
host returned 403, so the SVG-first approach was used. Run the fetcher locally
to swap in real photos.
